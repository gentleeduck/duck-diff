# Support

Thanks for using **@gentleduck/diff**.

- Read the [README](./README.md), and `duck-diff --help` for every command.
- In Neovim, `:checkhealth duck-diff` says what is off.
- Found a bug? [Open a bug report](https://github.com/gentleeduck/duck-diff/issues/new?template=bug_report.md).
- Have an idea? [Request a feature](https://github.com/gentleeduck/duck-diff/issues/new?template=feature_request.md).
- Security issue? See [SECURITY.md](./SECURITY.md), not the issue tracker.
