# Fonts

`SymbolsNerdFont-Regular.woff2` is Symbols Nerd Font from [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts)
v3.5.1 (`NerdFontsSymbolsOnly.tar.xz`, sha256 `01172f37db8543edb102e5cb5c64101c9f4686630804d49b419aa07b23a69996`),
converted from TTF with `woff2_compress`. It carries only icons, so the page's text stays JetBrains Mono and
anyone without a Nerd Font installed still sees the file tree's and the terminal's icons.
